I calibrated the SEARCH agent's planning and synthesis prompts while keeping the original judge rubric and gpt-4o-mini model unchanged. Planning now distinguishes specification questions describing CRUD behavior from requests to execute mutations. Synthesis requires exact evidence support and explicit limits on unsupported parts.

A real full-search example: for “Which actions should the initial maintenance grid provide for creating, editing, consulting, and deleting records?”, the old answer was “This request cannot be answered by read-only timeline fact search.” After the prompt change, the answer included “The user can navigate to an existing record from the grid to update (edit) it.” Its cited source explicitly says “From the grid you can delete a record or navigate to one to update it”; cited facts also support creating records, consulting the grid and deleting records. I independently checked that evidence rather than relying only on the judge.

The single 17-question replay returned 16 responses and one citation-validation failure. The fixed judge produced 13 good / 3 bad predictions and one NoAnswer error. These are unvalidated predictions: new human labels are required before reporting accuracy, precision or recall. Important problems remain: an unsupported consult-screen limitation, User/UserRoles confusion, a repeated project-list refusal, and duplicate context citations preventing one answer. The experiment demonstrates one observed improvement, not a general correctness gain. This was a SEARCH-agent prompt change, NOT a judge-prompt improvement experiment.
