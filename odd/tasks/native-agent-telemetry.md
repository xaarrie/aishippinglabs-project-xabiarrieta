## Scope and privacy contract
- Enable native SDK instrumentation centrally in both CreateAgent and CreateHarnessAgent, using supported installed APIs with sensitive-data capture disabled.
- Preserve exactly-once per-provider usage accounting, structured validation, injected raw GetChatClient identity, cancellation/errors and existing streaming contract. Do not invent tool/model spans from completed response messages or emit duplicate native chat spans.
- Register native source only with dedicated sanitation before exporter processing. Fixed/coarsened display names and explicitly allowlisted operation/model/agent metadata; numeric nonnegative usage counts where available. Arbitrary configured/provider/tool strings are untrusted, not automatically exported.
- No prompts/responses/instructions, tool descriptions/arguments/results, credentials, raw exception details, arbitrary event/link attributes, tracestate or other payloads in final OTLP bytes. Clear descriptions and untrusted tags; supported Activity APIs cannot remove events/links, so contaminated native spans fail closed/drop unless installed SDK provides proven suppression. Existing safe wrapper spans remain to show operation failures; dropped native spans may leave gaps.
- Do not enable native metrics/log export, SDK retries, streaming instrumentation, dependency upgrades or alter sampling. ParentBased and incoming unsampled decisions remain respected.
- Library instrumentation is backend-neutral; egress privacy is enforced by configured host. Other consumers subscribing the native source must install equivalent sanitation; EnableSensitiveData=false alone is not a complete exception privacy guarantee.
