## Exploration and decisions
Production source uses gpt-4o-mini chat and text-embedding-3-small embeddings. Current AgentCostSession accepts optional caller catalog but null means no tariffs; calculation and telemetry total fields already exist. AgentCostTotals is an immutable result record, not a mutable tariff table. Add a separate immutable default USD catalog consumed by accounting, preserve result DTO and all caller-owned catalogs. Explicit catalog (even empty) remains authoritative; null uses built-in rates ONLY for USD. Other currencies without explicit rates stay unknown, never implicit FX. Response model ID wins, exact lookup only; explicitly list official dated alias, no fuzzy model inference.

Official rates verified2026-10-25 from https://developers.openai.com/api/docs/models/gpt-4o-mini and https://developers.openai.com/api/docs/models/text-embedding-3-small:
- gpt-4o-mini and documented default snapshot gpt-4o-mini-2024-07-18: USD/1M tokens input0.15, cachedinput0.075, output0.60.
- text-embedding-3-small: USD/1M embedding inputtokens0.02; no text output charge. No cached tariff claimed.
Catalog is a dated estimate, not provider invoice/live pricing. gpt4omini page marked deprecated without shutdown date found; no model upgrade authorized.

## Accounting and scope
Preserve decimal arithmetic, exact aliases, actual usage counts, overflow/unknown/in-flight handling, concurrent and nested session lifetime/no doublecount. Cache/reasoning are subsets, not extra tokens. Missing discount-sensitive cached counts keep total unknown; known subtotal remains partial. Never assume missing usage or unknown model costs zero. No retroactive invention of costs for prior bulk calls.
Record official embedding SDK usage once at provider boundary into same accounting; output tokens are zero for embeddings, reported input/total must be validated. Preserve invalid-vector/error/cancellation accounting without double-completing calls. Injected raw chat getter identity/streaming scope unchanged. Owned session for embedding only when no current session, disposed after awaited operation; no prematurely disposed scopes.
Automatic framework cost session in backend-neutral AgentTelemetry.RunAsync only when no caller/current scope, so ordinary LocalCustomAgent/LocalCustomHarnessAgent runs emit per-run aggregate cost without callers wiring prices. Existing SearchEntriesAgent explicit session still owns multi-turn operation. Raw SDK factory/direct client/streaming contracts remain explicitly documented, no imaginary global invoice total.
Use existing telemetry fields agent.session.estimated_total_cost, known_estimated_cost, estimated_cost_complete, unknown_cost_call_count, currency; numeric values and completeness must survive final in-memory OTLP protobuf. Do not duplicate calculation/export or emit user payloads/credential data.
